# Logic-League.com

Public holding page for the Logic League project.

## Scope

This repository contains only the static public site deployed through GitHub Pages. The private production repository remains separate. The current wordmark is a typographic presentation for this holding page, not an approved permanent logo or final visual identity.

## Deployment

- Source: `main` branch, repository root
- Custom domain: `Logic-League.com`
- Host: GitHub Pages

No build step is required. Serve this directory with any static HTTP server for local review.
